**기존 추가 Train 쿼리의 multi-query 기반 선별 설계**

목표는 `tvrtrain.caption.with_additional.txt`에 들어 있는 추가 쿼리 중, 동일 원문의 검색 의도를 보존하면서 쿼리 집합에 유용한 검색 반응을 제공하는 후보를 선별하는 것이다. 선별 단계에서는 기존 `best.ckpt`를 동결한다. 전체 Holmes 재학습이나 추가 쿼리 생성은 선별의 전제 조건이 아니다.

**확인한 입력과 적용 범위**

동명의 병합 파일은 `additional_captions`, `additional_captions_unfiltered`, `additional_captions_rank1` 폴더에 각각 있다. 실제 실행에서는 병합 파일과 같은 폴더의 후보 CSV·생성 연결 CSV를 한 묶음으로 지정해야 한다.

이번에 직접 확인한 최신 `additional_captions_rank1` 자료는 원문 87,174개와 추가 366,444개로 이루어진다. 후보 CSV의 대표 `source_caption_id` 기준으로 원문 86,358개에 후보가 있으며, 원문당 평균 4.24개, 중앙값 4개, 95백분위 8개, 최대 32개다. 중복 생성된 후보의 다른 출처는 `links/generation_links_*.csv`에 보존되어 있으므로, 실제 쿼리 집합 구성에는 이 전체 연결을 사용한다. 위 후보 수 분포는 대표 출처 기준이며 전체 연결을 합친 분포와 구별한다.

현재 후보는 한 문장의 한 표현 위치를 대치한 결과다. 같은 영상에 속한 다른 원문은 별도의 사건일 수 있으므로, 선별 단위는 영상 전체가 아니라 `source_caption_id`로 연결된 원문과 그 변형들이다. 최종 파일에서는 원문을 모두 유지하고 선택된 추가 ID만 중복 없이 붙인다.

**ECCV 논문에서 가져오는 개념과 새로 제안하는 부분**

[ECCV 2022 Multi-Query Video Retrieval](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136740227.pdf)은 쿼리별 유사도를 평균하는 SA와, 쿼리 특징의 평균·가중 집계를 비교한다. 텍스트 간 유사도 및 학습된 가중치를 통해 쿼리의 정보성과 상대적 품질을 고려한다. 논문 자체가 증강 학습에서 반드시 필요한 문장을 판별하는 방법을 제공하는 것은 아니다.

아래의 집합 단위 기여도 선별은 SA와 상보성 개념을 현재 자료에 맞게 확장한 제안이다. 논문의 수치나 성능 보장을 그대로 이전하지 않는다.

**의미 보존을 먼저 확인할 이유**

확인한 후보에는 `picks up`의 일부가 `choices up` 또는 `blames up`으로 바뀐 사례가 있다. 표현이 달라졌다는 사실만으로 유효한 영상 설명이 되는 것은 아니다. 다른 단어들이 그대로 남아 있으면 부적절한 대치문도 교사 모델에서 높은 점수를 받을 수 있다.

신규 선별 결과에서는 원동작·참여자·객체·시간 관계 보존, 시각적으로 확인 가능한 표현, 확인된 근거에 한정한 대명사 해소, 의미를 보존하는 부정·감정 표현의 시각화를 확인한다. 추가 쿼리에는 14–20단어 및 동일 RoBERTa tokenizer 기준 30개 미만의 subword token 제약을 적용한다. 원문은 길이와 무관하게 보존한다. 불명확한 의미·시각적 상태는 검토 대상으로 기록한다. 검색 특징만으로 의미 동등성을 확정할 수는 없다.

기존 unfiltered/rank1 파일은 수정하지 않는다. 이는 새 선별본의 품질 조건이며, 기존 생성 단계의 필터 설정을 소급 변경하는 작업이 아니다.

**동결된 체크포인트에서 필요한 계산**

1. 체크포인트의 backbone, 특징 추출 모델·레이어·정규화, branch 가중치, `edl_tau`를 고정한다.
2. Train 영상의 frame/clip 표현을 한 번 인코딩해 캐싱한다.
3. 원문과 추가 쿼리에 해당하는 입력 텍스트 특징을 준비하고, 같은 체크포인트의 query 인코더로 처리한다. 새 문장의 특징은 원문 embedding을 복사하는 것으로 대체할 수 없다.
4. `multisrc`에서는 pooled clip-query 표현뿐 아니라 frame-query의 token 표현과 mask도 native 계산에 맞게 사용한다.
5. 각 원문 집합에서 모든 후보를 동일한 Train 영상 후보 집합으로 평가한다. 영상 블록 처리와 집합별 캐시를 사용하며, 전체 추가 쿼리 × 전체 영상 행렬을 한꺼번에 보관할 필요는 없다.

출력은 각 쿼리의 native clip/frame 점수, 원문 집합 ID, 정답 Train 영상 ID, 필요한 uncertainty 통계다. 후보 집합의 크기나 구성을 바꾼 결과의 uncertainty를 같은 기준으로 취급하지 않는다.

**선별 목적 함수**

원문을 q0, 추가 후보를 q1,...,qm, 정답 Train 영상을 v+라고 하자. s(q,v)는 체크포인트의 native clip/frame 가중 검색 점수다. 추가 후보의 부분집합 A에 대해 평균 검색 점수를 정의한다.

`S_A(v) = [s(q0,v) + Σ_{q∈A} s(q,v)] / (1 + |A|)`

첫 비교 기준으로 정답과 가장 높은 오답의 점수 차이를 사용한다.

`M(A) = S_A(v+) - max_{v≠v+} S_A(v)`

`G(A) = M(A) - M(∅)`

G(A)는 원문만 사용했을 때보다 쿼리 집합의 검색 구분력이 좋아지는지를 나타내는 교사 모델 기반 대리 지표다. 정답 영상은 Train annotation에서 사용한다. 이 지표 자체가 향후 학습의 성능 증가량은 아니다.

**첫 선별 실험의 집합 크기와 중복 처리**

원문당 추가 후보 0개·1개·2개를 비교한다. 원문은 항상 포함한다. 의미 보존 조건을 만족한 후보들에 대해 단일 추가와 후보 쌍을 평가한다. 두 후보가 각각은 불리해도 서로 다른 오답 반응을 상쇄할 수 있으므로, 개별 순위 상위 두 개만 고르는 방식과 구별한다.

후보 두 개의 상보성은 반복 대조군으로도 확인한다. `원문 + qi + qj`를 `원문 + qi + qi`, `원문 + qj + qj`와 동일한 평균 집계로 비교한다. 서로 다른 두 후보의 결과가 더 좋지 않다면, 추가 이득이 원문의 상대 가중치 감소나 비슷한 반응의 반복에서 생겼을 수 있다. 첫 상보성 선별 조건에서는 이 경우 두 후보를 모두 필요하다고 판정하지 않고 단일 후보 선택을 우선한다. 이는 ECCV 논문이 제시한 선별 규칙이 아니라 이번 설계의 대조 조건이다.

첫 실험의 추가 개수 2는 비용을 제한하는 설정이며 ECCV 논문의 필수 조건이 아니다. 후보가 많은 입력 버전에서는 먼저 검토 가능한 소규모 원문 집합으로 계산량을 확인한다. 선별 수를 고정적으로 채우지 않는다.

원문 대비 gain이 임계값 ε를 넘지 않으면 추가 쿼리를 남기지 않는다. 후보를 하나 제거했을 때 margin 손실이 ε 이하라면 그 후보는 현재 집합에서 불필요한 것으로 취급한다. 동률이면 작은 집합을 우선하고, 그 뒤에는 고정된 ID 순서로 결정한다. 임계값·수치 허용 오차와 실제 선택 경로를 audit에 저장한다.

동일한 추가 ID가 여러 원문에 연결되면 각각의 집합에서 기여도를 평가하되, 최종 병합 파일에는 한 번만 기록한다. 선택된 출처와 선택되지 않은 출처를 모두 연결 기록에 남긴다.

**Uncertainty를 사용하는 범위**

첫 선별 기준은 의미 보존과 G(A)다. uncertainty가 가장 낮은 문장만 고르면 과신하는 잘못된 문장이 선택될 수 있다. 기존 Holmes uncertainty는 원문 난이도별 선별 효과와 쿼리 집합의 반응을 분석하는 보조 신호로 기록한다. 효과를 확인한 다음 uncertainty 기반 선별과 무작위 선별을 동일한 추가 쿼리 수로 비교한다.

추가 쿼리마다 evidence를 단순 합산해 uncertainty를 낮추는 것을 gain으로 정의하지 않는다. 원문 반복 대조군을 사용하면 새로운 정보 없이 strength만 증가하는 현상을 구별할 수 있다.

**결과물과 검증의 의미**

예정 결과물은 원문과 선택된 추가 ID를 담은 `tvrtrain.caption.selected.txt`, 각 후보·집합의 의미/길이 검토 상태와 점수·gain·채택 사유를 담은 `selection_audit.csv`, 입력 파일·체크포인트·설정·seed의 식별 정보를 담은 manifest다. 원문 보존, ID 충돌, 영상·원문 연결, 선택 ID의 중복을 검증한다.

동결 모델에서 margin이나 Train Recall이 개선된 결과는 후보를 줄이는 근거다. 교사 모델이 선호하는 쉬운 후보에 치우치거나, 학습에 유용한 어려운 후보가 제외될 수 있다. 선정된 데이터가 모델 학습을 실제로 개선한다는 주장은 별도의 학습·평가가 필요하다. 그 검증에서는 같은 수의 무작위 추가 쿼리를 사용한 대조군과 초기 체크포인트·학습 step·seed를 맞춘다. 가능한 경우 best.ckpt부터 짧은 fine-tuning 비교로 시작하고, 선별 단계에서 반복적인 전체 재학습은 수행하지 않는다.

이 문서는 선별 설계다. 추가 쿼리의 checkpoint 특징·검색 점수를 계산하거나 최종 선택 파일을 생성한 결과가 아니다.
