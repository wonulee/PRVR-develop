# 공식 사전 범위에 맞춘 기존 치환 수정

사전 근거가 없었던 기존 8개 치환만 제거했습니다. 8개 캡션만 변경됐으며 나머지 기존 변경은 보존했습니다.
원본 대비 최종 변경은 1,031개 캡션 / 1,132개 쌍 / 1,150회 치환입니다. 변경된 캡션은 14–20단어·RoBERTa 30 미만 토큰 조건을 모두 만족합니다.

approved_pairs.csv는 두 공식 aspect 사전과 사전 제한 Val 추출에 근거가 있는 기존 쌍입니다.
repair_verification.json은 변경 ID·해시·백업·적용 검증을 담습니다. LLM은 사용하지 않았습니다.
