# Validation-pool semantic candidates

`tvrtrain_rewriting_with_val_candidates.csv`: all original OOD captions, with JSON action/object candidate lists per OOD lemma.
`tvrtrain_val_replacement_pairs.csv`: one row per caption, OOD lemma and candidate; easier to filter in Excel.
`ood_lemma_val_candidates.csv`: shared lemma-level candidates, using the original train examples as context.
`summary.json`: counts, ranking method, model/corpus versions, input hashes and limitations.

Candidates are the top 5 after same-type Val pool membership, direct WordNet antonym exclusion and heuristic source-sense filtering. Each includes term cosine, validation context cosine, relation, source sense definition and an actual validation caption containing its lemma/expression. All observed phrasal-verb occurrences are eligible as evidence; synonym example selection also uses the selected sense definition. Caption rankings may differ from global lemma rankings because the source caption can change the selected sense.

`candidate_expression` is the expression to consider; `candidate_lemma` is its pool member/head. Actions may include verb particles only when the phrasal expression is observed in a validation caption, e.g. `throw up` retains the `throw` head in the Action Pool. Objects remain original Object Pool lemmas. Tier 0 (morphology/same-sense synonyms) always precedes tier 1 (broader hypernyms), which precedes tier 2 (embedding-only). Scores order candidates within each tier. Relations distinguish morphology, same-sense synonym, broader hypernym and embedding-only proximity. All candidates require semantic review; `safe_to_auto_substitute=False` throughout. A broader term loses detail; a nearby vector can be a co-occurring object or action rather than a synonym. WordNet can miss antonyms and the embedding model can select the wrong sense. The word-cosine cutoff 0.55 only marks weak retrieval results, not equivalence. `terms_without_strong_candidate` identifies OOD terms without a selected lexical/morphological match or sufficiently similar embedding result. Those terms still retain their nearest retrieval candidates for inspection.

For a later LLM rewrite, use the original caption and supported candidate meanings, preserve the unique timestamp-specific action and visible objects/interactions, resolve pronouns without inventing identity, convert negation to visible affirmative states and emotions to visible expressions, and enforce 14–20 words and fewer than 30 subword tokens. If the object/action cannot be faithfully expressed using the pool, retain it for manual review. No rewritten caption is generated by this script.
