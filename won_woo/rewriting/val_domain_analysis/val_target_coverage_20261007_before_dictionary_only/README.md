# Val 용어 기준 Train 어휘 부족 및 치환 후보 조사 — 2026-10-07

현재 `tvrtrain.caption.txt` 87,174개와 `tvrval.caption.txt` 10,895개를 기준으로, 최상위 `diagram_synonym_pairs`와 문맥 검토가 반영된 기본형별 영역표를 조사했습니다. LLM을 사용하지 않았으며 caption, 영역 원본, 모델 및 특징 파일을 변경하지 않았습니다.

**Train 원문에도 없는 Val 표현은 316개이며, 이 중 현재 CSV의 Train→Val 유의어 후보로 연결되는 것은 95개, 연결이 없는 것은 221개입니다.** Object/Action을 분리한 기본형 수입니다. 실제 문맥을 보존하는 치환 수는 아직 확정하지 않았습니다.

## A/B/C의 의미와 다이어그램 수치

| 영역 | Object | Action | 해석 |
| --- | ---: | ---: | --- |
| A Train | 2,875 | 882 | Val의 동일 품사 기본형 및 선택 WordNet 의미와 연결되지 않는 Train 용어 |
| B Train | 2,991 | 1,595 | Val과 동일 기본형 또는 유의어 의미가 연결된 Train 용어 |
| B Val | 2,209 | 1,006 | Train과 동일 기본형 또는 유의어 의미가 연결된 Val 용어 |
| C Val | 322 | 81 | Train과 위 연결이 없는 Val 용어 |

B Train과 B Val은 각 split의 서로 다른 기본형 수입니다. B 자체가 같은 문자열의 단순 교집합은 아닙니다. A에는 현재 CSV 기준 Val로 바꾸는 유의어 후보가 없으며, 치환 후보는 B에서 찾았습니다. C를 새로 채우는 것은 현재 사전 매핑의 유의어 치환 범위를 벗어납니다.

## Val 기준: 추출 어휘의 공백과 원문 부재를 구분

| 구분 | Object | Action | 합계 |
| --- | ---: | ---: | ---: |
| Val 전체 유효 기본형 | 2,531 | 1,087 | 3,618 |
| Train에 동일 품사 기본형 있음 | 2,071 | 951 | 3,022 |
| 동일 기본형은 없지만 유의어가 연결됨: B | 138 | 55 | 193 |
| 동일 기본형도 유의어 연결도 없음: C | 322 | 81 | 403 |
| 추출 어휘 기준 Train에 없음: B+C | 460 | 136 | 596 |
| 이 중 Train 원문에도 문자열이 없음 | 229 | 87 | 316 |
| 원문에도 없고 유의어 후보 있음: B | 57 | 38 | 95 |
| 원문에도 없고 유의어 연결 없음: C | 172 | 49 | 221 |

문자열 부재는 대소문자를 무시하고 Val 기본형 또는 Val에서 관측된 원래 표현을 Train caption에서 독립된 단어/구절 경계로 찾는 기준입니다. 모든 가능한 굴절형을 생성한 검사는 아닙니다. 동일 품사·동일 의미 존재와 구별합니다.

추출 기준 부족분 596개 중 280개는 Train 원문에 문자열이 있습니다. 예를 들어 Object `finger`는 추출 어휘에서는 없지만 Train 원문 1,115개 캡션에 나오고, Action `be`는 원문 23,057개에 나옵니다. `be`는 Val 2,824개 쿼리에 걸쳐 있어 추출 공백에 해당하는 쿼리 수를 크게 늘립니다. 이런 표현을 텍스트 인코더가 학습에서 전혀 보지 못한 신규 어휘로 해석해서는 안 됩니다. 품사/추출 방식 및 보조동사·대명사·합성어 처리를 먼저 구별해야 합니다.

## 원문에도 없는 B 용어 95개의 후보 규모

| 지표 | Object | Action | 통합 |
| --- | ---: | ---: | ---: |
| 대상 Val 기본형 | 57 | 38 | 95 |
| 현재 Train→Val 후보 행 | 5,742 | 22,399 | 28,141 |
| 후보가 있는 Train 캡션 | 5,618 | 14,597 | 19,371 |
| 단일 치환이 길이 조건만 통과하는 Val 기본형 | 51 | 32 | 83 |
| 길이 조건만 통과하는 후보 행 | 1,557 | 5,322 | 6,879 |
| 길이 조건만 통과하는 Train 캡션 | 1,525 | 3,463 | 4,725 |

통합 캡션 수는 Object/Action 중복을 제거했습니다. 19,371개는 전체 Train의 22.22%, 4,725개는 5.42%입니다. 후보 행은 같은 캡션의 서로 다른 표현·대안이므로 실제 변경 문장 수와 다릅니다.

길이 조건은 하나의 후보 표현을 동시에 단어 경계로 치환한 결과가 14–20단어이고 시작·종료 특수 토큰을 포함하여 30 미만 RoBERTa 토큰인지 검사합니다. 여러 대안을 함께 적용한 길이, 대명사 해석, 부정/감정의 시각화, 문법·문맥·동작·영상 정합성은 이 집계의 승인 조건이 아닙니다.

## 추출 기준 B 전체 193개를 대상으로 할 때

- 후보 행: Object 11,718 + Action 41,194 = 52,912개.
- 후보 Train 캡션: Object 9,916 / Action 28,327, 통합 35,123개.
- 길이 조건만 통과하는 기본형: Object 118 + Action 48 = 166개.
- 길이 조건만 통과하는 후보 행: 13,821개, 통합 Train 캡션 8,724개.
- C의 403개에는 후보 행이 0개입니다. 그중 185개는 WordNet 항목이 없으며, 신규 용어와 오타·추출 문제를 구분해야 합니다.

이미 동일 기본형이 Train에 있는 Val 용어까지 포함하면, 전체 WordNet 후보가 있는 원본 Train 캡션은 Object 68,682개, Action 81,012개입니다. 전체 후보 행은 Object 311,673 + Action 1,159,074 = 1,470,747개입니다. 이 규모는 신규 Val 어휘를 추가하는 규모와 구별됩니다.

## 문맥 검토 없이 바로 적용할 수 없는 이유

CSV의 의미 연결과 굴절 검증이 실제 문장 동치성을 보장하지 않습니다. 예를 들어 `make gestures`의 `make`가 Val의 `construct`와 연결되어 있지만 `construct gestures`는 원래 동작을 보존하지 않습니다. `horn→trumpet`도 차량 경적과 악기를 구별해야 합니다. `ban→censor`에서 간식을 못 먹게 하는 상황과 누드 사진 검열은 다른 의미입니다. 모든 실제 후보의 `requires_review=True`는 유지되어 있습니다.

C에는 `something`, `everyone`, 합성어 조각 `operating` 같은 추출 검토 대상과 `syringe`, `earring` 같은 구체적 명사가 함께 있습니다. C 전체를 새로운 시각 개념으로 단정하지 않았습니다.

## 앞선 1,037개 치환과의 관계

이전 변경은 이미 Train에 존재하던 기본형끼리의 치환이었습니다. 새 Val 기본형이 추가된 것은 0개입니다. 변경한 source의 모든 해당 캡션을 제거한다고 가정해도 원래 다른 캡션에서 해당 기본형이 남아 있고, target도 모두 기존 Train 어휘입니다. 따라서 원래 추출 기준 고유 어휘 집합은 동일합니다. 현재의 실제 source 문자열 존재 여부는 이번 집계에서 다시 확인했습니다. 원본 영역과 현재 문자열 상태를 혼동하지 않았습니다.
